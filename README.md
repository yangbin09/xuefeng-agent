## 它解决什么问题

填志愿最怕两件事：**分数不能直接比**，和**AI 张口就来**。

- 600 分在湖南 2025 是 15860 位，2026 可能是 18876 位——跨年比分数没有意义，得先换成位次。
- 大部分 AI 志愿工具没有数据，输出的学校和分数线是编的。

这个项目把两件事都做实了：本地录取库负责"有据可查"，位次引擎负责"跨年可比"，每条推荐都标注数据来源，没数据的学校绝不出现在结果里。

## 5 分钟跑起来

**Windows**

```
1. 装 Python（python.org，安装时勾选 Add to PATH）
2. 下载本项目 ZIP → 解压
3. 双击 启动.bat → 浏览器自动打开
4. 右上角 API 设置 → 填 DeepSeek Key → 保存测试
5. 打字提问
```

**Mac**

```
1. 装 Python（python.org）
2. 下载本项目 ZIP → 解压
3. 终端进入文件夹 → python3 server.py
4. 双击 打开我.html
5. 填 DeepSeek Key → 打字提问
```

> 完全零基础？看 [Windows 小白教程](docs/小白教程-零基础也能用.md) 或 [Mac 安装教程](docs/Mac安装教程.md)。
> 不知道该怎么问？看 [提问模板](docs/提问模板-这样问最准.md)。

## 功能

| 能力 | 说明 |
|---|---|
| 🗄️ 本地录取库 | 24 省 × 2024–2025 年官方投档线，42 万条，位次精确匹配 |
| 📐 位次引擎 | 一分一段表换算、冲/稳/保按位次分档、来源留痕（见 [engine/README.md](engine/README.md)） |
| 🎯 区间填报 | 给"585–605 分 + 选科组合"，输出冲稳保预演结果 |
| 📊 志愿表导出 | 一键导出 Excel，含近三年分档与学费标注 |
| 🤖 需求提取 | 自动识别省份、位次、专业偏好（"一万三" → 13000，"川籍" → 四川） |
| 🔍 联网搜索 | 填 Tavily Key 用 AI 搜索；不填走百度兜底 |
| 📋 省份政策感知 | 浙江 80 志愿 / 山东 96 志愿 / 老高考 8–12 所，自动适配 |
| 📝 自定义数据 | 填 `自定义数据.xlsx` 后只用你的表分析，不查系统库 |
| 💬 多轮对话 | 左侧会话独立保存，追问不用重复说 |
| 🔒 隐私 | 数据全在本地，Key 存在浏览器，不上传任何服务器 |

## 工作原理

```
你：浙江 655 分位次 10500，想学计算机电子，不接受调剂
        ↓
   AI 提取 → 省份:浙江  位次:10500  专业:计算机,电子
        ↓
   位次引擎 → 分数换算位次 → 按位次分冲/稳/保三档
        ↓
   本地库查询 → 只返回对口专业组 + 近三年分档 + 学费
        ↓
   联网搜索（可选）→ 校园环境、就业、王牌专业
        ↓
   输出 → 每条建议标注 [DB] 或 [联网]
```

## 数据说明

**第一层：录取数据库（`admission_clean.db.gz`）**

24 省 × 2024–2025 年官方投档线，42 万条。首次运行自动解压（29 MB → 143 MB）。
覆盖：浙江 · 河北 · 山东 · 重庆 · 黑龙江 · 江苏 · 湖南 · 湖北 · 北京 · 天津 · 上海 · 广东 · 河南 · 福建 · 陕西 · 甘肃 · 青海 · 宁夏 · 江西 · 内蒙古 · 海南 · 山西 · 云南 · 安徽

**第二层：位次引擎（`data/engine.db`）**

| 数据 | 来源 | 覆盖 |
|---|---|---|
| 一分一段表 | 省考试院（经 eol.cn 整理） | 湖南 / 广东 × 2024 / 2025 / 2026 × 物理 / 历史 |
| 校线 2023–2025 | 掌上高考静态索引（3145 校） | 全部院校 |
| 校线 2026 | `static-data.gaokao.cn` 实时接口 | 全部院校 |

原始文件固化在 `data/raw/`，重建方法与命令见 [engine/README.md](engine/README.md)。

> 数据来自各省教育考试院官方投档线，经多轮联网交叉验证。但录取数据每年变化，**最终以官方公布为准**。

## 支持哪些 AI

任何 OpenAI 兼容 API 都能用——右上角 API 设置里改 Base URL 和 Model 即可。

| 模型 | 推荐 | 说明 |
|---|---|---|
| DeepSeek | ⭐ 首选 | 便宜好用，有免费额度 |
| 通义千问 | 推荐 | 有免费额度 |
| 智谱 GLM | 推荐 | 国产稳定 |
| GPT-4o | 可选 | 贵，需要网络 |

联网搜索可选填 [Tavily](https://tavily.com) Key（有免费额度），不填则用百度兜底。

## 常见问题

**数据准不准？** 来自各省考试院官方投档线，多轮联网交叉验证。但录取数据每年变，最终以官方为准。

**要钱吗？** 个人使用免费。AI 调用按量计费（DeepSeek 聊几百次几毛钱）。

**能换别的 AI 吗？** 能，API 设置里改 Base URL 和 Model。

**怎么更新？** 重新下载 ZIP 覆盖文件夹；数据更新见 [更新说明](docs/更新说明.md)。

**支持手机吗？** 目前面向 Windows / Mac 电脑使用。
